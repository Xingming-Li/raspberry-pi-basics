# Raspberry Pi AI Vision Dashboard

A Raspberry Pi-based edge AI system for real-time object detection and monitoring.

## Features

* Live camera streaming
* YOLOv8 object detection
* Web-based dashboard
* CPU, memory, and temperature monitoring
* FastAPI backend and Next.js frontend

## Tech Stack

* Raspberry Pi
* Python, FastAPI, OpenCV
* YOLOv8
* Next.js, React, TypeScript
* WebSockets
